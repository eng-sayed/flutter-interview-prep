# Flutter Interview Ladder

228 Flutter & Dart interview questions (Arabic), ordered Junior → Mid → Senior, with problem solving, HR questions, System Design, Design Patterns, a timed mock-interview mode, and a review of recent Flutter/Dart changes. Each answer can be shown or hidden, and you can rate yourself on every question.

The latest additions consolidate gaps found in the supplied interview guide, Dart/OOP notes, Design Patterns PDF, System Design handbook, and the previous interview-preparation chats. Duplicate questions were intentionally skipped.

**Repository:** https://github.com/eng-sayed/flutter-interview-prep

- `index.html`: the complete self-contained study website.
- `README.md`: project overview and source notes.
