# Flutter Interview Ladder

Flutter & Dart interview questions (Arabic), ordered Junior → Mid → Senior, with problem solving, HR questions, English interview practice, System Design, Design Patterns, a timed mock-interview mode, and a review of recent Flutter/Dart changes. Each answer can be shown or hidden, and you can rate yourself on every question. The Add-to-App topic includes interview questions and a practical Android/iOS exercise path.

The latest additions consolidate gaps found in the supplied interview guide, Dart/OOP notes, Design Patterns PDF, System Design handbook, and the previous interview-preparation chats. Duplicate questions were intentionally skipped.

**Repository:** https://github.com/eng-sayed/flutter-interview-prep
